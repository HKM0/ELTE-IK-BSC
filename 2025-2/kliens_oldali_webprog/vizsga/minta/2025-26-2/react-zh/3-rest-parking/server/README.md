# Parking API (kész szerver)

Ez a mappa **elkészült backend**. A ZH során **nem kell módosítanod** — csak elindítani.

```sh
npm install
npm run dev
```

| | URL |
|---|-----|
| API | http://localhost:3031 |
| **OpenAPI (Swagger UI)** | **http://localhost:3031/docs** |

A végpontok, request/response mezők és példák a **/docs** oldalon vannak.

- Memória DB: újraindításkor az adatok visszaállnak
- **ENTER** a terminálban: aktuális `spots` / `sessions` táblázat

A feladat megoldása kizárólag a **`../client`** mappában történik.
