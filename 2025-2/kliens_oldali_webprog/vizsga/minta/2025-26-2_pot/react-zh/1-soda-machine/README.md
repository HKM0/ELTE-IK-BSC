# Zöldségautomata – megoldás (TypeScript)

```sh
npm install
npm run dev
```

## Komponensek

| Fájl | Feladat |
|------|---------|
| `App.tsx` | State és logika |
| `MachineLayout.tsx` | Keret, cím, kijelző, lábak |
| `types.ts` | `Product`, `ProductWithStock`, `DispensedProduct` |
| `ProductGrid.tsx` | Rekeszek |
| `PaymentPanel.tsx` | Kiválasztott + fizetés |
| `DispenseTray.tsx` | Kiadónyílás |
