# Kiberbiztonság Alapjai - vizsga

Az előadás pdf-ekből összerakott összefoglaló [**itt**](osszefoglalo.md) érhető el.

| | |
|---|---|
| **Kérdések formátuma** | 30 feleletválasztós kérdés, kérdésenként egyetlen helyes válasszal |
| **Vizsgaplatform** | A vizsga a Canvas felületén zajlik; vizsga előtt ellenőrizd a belépést! |
| **Teljes időtartam** | 1 óra (tartalmazza a kezdeti beléptetést és azonosítást) |
| **Tényleges vizsgaidő** | ~30 perc |
| **Vizsgaterem** | 0.308-as terem, más néven a „Lovarda” |
| **Idősávok vizsganaponként** | 2 idősáv; a hallgatók a nekik megfelelőre jelentkezhetnek |
| **Kapacitás idősávonként** | Összesen 80 férőhely |
| **Maximális próbálkozás** | 3 vizsgaalkalom engedélyezett |

> **Fontos: Az utolsó érdemjegy számít!**
> Ha újra leteszed a vizsgát, a legutóbbi érdemjegyed lesz a végső jegyed, még akkor is, ha az rosszabb egy korábbi eredményednél. Ez az elégtelen (1) osztályzatra is vonatkozik. Tervezd meg gondosan a próbálkozásaidat!

| **Érdemjegy** | **Helyes válaszok** | **Megengedett hibák max. száma** | **Megjegyzés** |
|---|---|---|---|
| 5 (Jeles) | 28–30 | 2 vagy kevesebb | Kiváló |
| 4 (Jó) | 25–27 | 3–5 | Jó |
| 3 (Közepes) | 22–24 | 6–8 | Megfelelő |
| 2 (Elégséges) | 19–21 | 9–11 | A sikeres vizsga minimuma |
| 1 (Elégtelen) | 0–18 | 12 vagy több | A ponthatár alatt |

> **Ponthatár:** A vizsga sikeres teljesítéséhez legalább 19 helyes válaszra (a 30-ból) van szükség.
